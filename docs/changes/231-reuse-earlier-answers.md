# Search and reuse earlier cover-letter answers (#231)

While editing the questions of an application, each answer has a "Find earlier answers" button. It searches the questions and answers of the other applications and copies the chosen answer into the field. Nothing is saved until the user saves the form.

| File                                                         | Change                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `backend/src/routes/cover-letter-questions.ts`               | New `GET /api/cover-letter-answers?q=&exclude=`: case-insensitive text match on question or answer (`%`, `_`, `\` are plain text), skips questions without an answer, leaves out the `exclude` application, newest application first, at most 20 rows with company, position and the day the application was added (Asia/Seoul) |
| `backend/src/openapi.ts`, `docs/openapi.json`                | The new operation                                                                                                                                                                                                                                                                                                               |
| `frontend/src/cover-letter-earlier-answers.tsx`              | Dialog with a search box, matches (company, position, date, question, answer) and "Use this answer"                                                                                                                                                                                                                             |
| `frontend/src/cover-letter-data.ts`, `cover-letter-form.tsx` | `EarlierAnswer` type and `useEarlierAnswers`; the button under each answer fills the draft (cut at 5000 characters, the server limit)                                                                                                                                                                                           |
| Tests                                                        | Backend validation tests, a DB integration test (Korean text, no matches, excluding the current application, wildcard characters), and a form screen test (search, no match, pick, save)                                                                                                                                        |

The DB integration test needs PostgreSQL and runs in CI only.
