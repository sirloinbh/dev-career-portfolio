## 목적

#46 목록에서 자격증을 추가·수정·삭제할 수 있게 합니다. 구조는 #41 이력 폼과 같습니다. 폼 상태, 서버 메시지 나누기, 삭제 처리는 공용 코드(`form-state.tsx`, `field-errors.ts`, `delete-item.ts`)를 그대로 씁니다. 입력 항목은 #35에서 확정한 내용입니다.

  - `NewCertification`, `EditCertification`, 공용 입력 폼 `CertificationFields`를 추가했습니다.
  - 목록은 `useReloading`으로 바꿔, 삭제한 뒤 목록을 다시 불러오는 동안에도 남은 항목을 화면에 둡니다.
- `frontend/src/certification-form.test.tsx`: 등록, 서버 메시지 표시와 초점, 수정, 만료일 비우기, 없는 항목 수정, 삭제 취소·확인·실패·이미 지워진 경우, 덜 입력한 날짜, 키보드 사용을 위한 구조(기본 입력 칸이 화면 순서대로 있고 폼 안에 제출 버튼이 있음), 메시지 대응표, 값 변환(16건). 실제 Tab·Enter 입력은 아래 브라우저 확인에서 했습니다.

## 입력 폼

| 칸        | 입력                                | 비고                                                                                   |
| --------- | ----------------------------------- | -------------------------------------------------------------------------------------- |
| 자격증명  | 글자, 최대 100자                    | 필수                                                                                   |
| 발급 기관 | 글자, 최대 100자                    | 필수                                                                                   |
| 취득일    | 날짜                                | 필수                                                                                   |
| 만료일    | 날짜                                | 비우면 `null`로 보내고 목록에 "만료 없음"으로 보입니다. 칸 아래에 같은 안내가 있습니다 |
| 점수·등급 | 글자, 최대 50자(예: 905점, 1급, IH) | 선택                                                                                   |
| 메모      | 여러 줄, 최대 2000자                | 선택                                                                                   |

## 판단한 내용

- **검증은 서버가 합니다.** 폼은 `noValidate`이고, 서버가 돌려준 한국어 메시지를 메시지가 가리키는 칸 아래에 보입니다. 여러 칸이 틀렸으면 맨 위 칸으로 초점을 옮깁니다. 칸을 가리키지 않는 메시지는 폼 아래 알림에 보이고, 초점은 저장 버튼으로 돌아갑니다(#39 구조).
- **덜 입력한 만료일은 "만료 없음"으로 저장하지 않습니다.** 브라우저는 "2027-03-__"처럼 덜 입력한 날짜를 빈 값으로 읽습니다. 그래서 이력 폼의 퇴사일처럼 `incomplete`를 보내고, 서버의 날짜 형식 메시지가 만료일 칸 아래에 보이게 했습니다.
- **수정 화면은 목록에서 항목을 찾습니다.** #35에 단건 조회 API가 없습니다. 항목 수가 적어 다른 항목 폼과 같은 방식으로 찾습니다.
- **삭제:** 확인 창에서 취소하면 요청을 보내지 않습니다. 이미 지워진 항목(404)은 지운 것으로 봅니다. 안내 문구와 404 처리는 `delete-item.ts` 공용 동작입니다. 삭제한 뒤 초점을 페이지 제목으로 옮기는 일은 이력 목록과 같이 목록 화면(`certifications.tsx`)에서 합니다.
